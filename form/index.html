ng-dynamic-form

Angular 20+ dynamic reactive forms with validators, layouts, repeatable arrays, custom templates, public methods, and explicit output events.

Download & install

Install the Angular package in an Angular 20+ project that uses Reactive Forms.

Terminal
npm install ng-dynamic-form

Usage

Import the standalone DynamicForm component, pass a typed formType config, and listen to explicit outputs.

Angular component
import { Component } from '@angular/core';
import { DynamicForm, type DynamicFormSubmitEvent, type formType } from 'ng-dynamic-form';

@Component({
  selector: 'app-user-form',
  imports: [DynamicForm],
  template: `
    <ng-dynamic-form
      [options]="options"
      (formSubmit)="save($event)"
      (invalidSubmit)="showErrors($event)"
    ></ng-dynamic-form>
  `
})
export class UserFormComponent {
  protected options: formType = {
    config: [
      { type: 'text', name: 'firstName', label: 'First Name', validators: ['required'] },
      { type: 'email', name: 'email', label: 'Email', validators: ['required', 'email'] }
    ]
  };

  save(event: DynamicFormSubmitEvent) {
    console.log(event.value);
  }
}

Validators and errors

Use built-in validators, pattern, min/max, and field-specific error messages.

Example code
const config: configOptions[] = [{
  type: 'text',
  name: 'username',
  label: 'Username',
  validators: ['required', 'pattern'],
  pattern: '^[a-z0-9_]+$',
  errorMessages: {
    required: 'Choose a username.',
    pattern: 'Use lowercase letters, numbers, or underscores.'
  }
}];

Conditional logic

showIf and requiredIf react to the full raw form value.

Example code
{
  type: 'text',
  name: 'companyName',
  label: 'Company Name',
  showIf: value => value['accountType'] === 'business',
  requiredIf: value => value['accountType'] === 'business'
}

Repeatable formArray

Add and remove repeated groups while keeping clean array output.

Example code
{
  type: 'formArray',
  name: 'addresses',
  label: 'Addresses',
  minItems: 1,
  maxItems: 3,
  children: [
    { type: 'text', name: 'street', label: 'Street', validators: ['required'] },
    { type: 'text', name: 'city', label: 'City', validators: ['required'] }
  ]
}

Output events

Listen to submit, reset, value, status, field, invalid submit, and legacy getValue.

Example code
<ng-dynamic-form
  [options]="options"
  (formSubmit)="log($event)"
  (invalidSubmit)="log($event)"
  (valueChange)="log($event)"
  (statusChange)="log($event)"
  (fieldChange)="log($event)"
  (formReset)="log($event)"
  (getValue)="legacy($event)"
></ng-dynamic-form>

Outputs / events

New output names provide clear hooks for submit, reset, live value changes, status changes, field changes, and invalid submit attempts.

OutputEmits when
formSubmitEmits a full snapshot when a valid, non-pending form submits.
invalidSubmitEmits a full snapshot after marking invalid controls touched.
formResetEmits a full snapshot after reset restores defaults.
valueChangeEmits clean value, rawValue, status flags, and flattened errors.
statusChangeEmits when Angular form status changes.
fieldChangeEmits path, field config, field value, field status, and snapshot.
getValueLegacy output for clean value on valid submit and reset.
